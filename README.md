# 🤖 AI Student Assistant

A modern and responsive Student Productivity Dashboard built using HTML, CSS, and JavaScript.

## 🌐 Live Demo

https://tuntunyadav802217g-hash.github.io/AI-Student-Assistant/

## ✨ Features

- 📊 Student Performance Analysis
- 📈 Marks and Percentage Calculation
- 🎯 Target Marks Tracking
- 📅 Automatic Study Planner
- ⏱️ Study Timer
- 📝 Assignment / Task Manager
- 📚 Attendance Tracking
- 🧑‍🎓 Student Profile
- 🌙 Dark / Light Mode
- 💾 Local Storage
- 📱 Responsive Design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- GitHub Pages
